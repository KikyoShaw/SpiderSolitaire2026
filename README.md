# 青绿牌室 · 蜘蛛纸牌

使用 **Tauri 2 + Vue 3 + TypeScript** 实现的离线蜘蛛纸牌。绿色绒面牌桌、十列布局，支持点击和拖拽操作；浏览器开发模式和 Windows 桌面版使用同一套游戏代码。

## 游戏功能

| 难度 | 花色 | 牌数 |
| --- | --- | --- |
| 闲庭信步 · 简单 | 黑桃 | 104 |
| 渐入佳境 · 普通 | 黑桃、红桃 | 104 |
| 步步为营 · 困难 | 黑桃、红桃、梅花、方块 | 104 |

- 点击选中明牌或合法牌组，再点击目标列；也可以直接拖动。
- 自动翻开露出的暗牌，自动收走同花色 K → A 的完整牌组。
- 最近 200 步撤销，包含移牌、发牌及其触发的翻牌、收组。
- 循环显示合法移动提示；提示只查看明牌，不保证一定可以获胜。
- 新游戏重新洗牌；重新开始使用相同种子还原本局最初布局。
- 暂停、计时、分数、步数和胜利界面。
- 自动在本地保存牌局、用时和撤销记录，关闭后可以续玩。
- 自适应窗口，长牌列可以滚动；拖动接近牌区上下边缘时自动滚动。

## Windows 开发环境

桌面开发需要：

1. Node.js 22 LTS 或兼容 Vite 6 的版本，以及 npm。
2. Rust stable，使用 `x86_64-pc-windows-msvc` 工具链。
3. Visual Studio 2022 Build Tools 中的“使用 C++ 的桌面开发”工作负载及 Windows SDK。
4. Microsoft Edge WebView2 Runtime，Windows 10 如未安装需要先安装。

纯浏览器开发只需要 Node.js 和 npm。

## 启动

在 PowerShell 中执行：

```powershell
cd G:\KikyoDemo\KikyoShaw\Tauri\SpiderSolitaire2026
npm install
npm run desktop:dev
```

首次桌面启动需要 Cargo 下载和编译 Tauri 依赖，耗时取决于网络与工具链。程序启动后游戏本身不需要网络。

仅预览前端：

```powershell
npm run dev
```

打开 `http://127.0.0.1:1430`。Vite 固定使用 1430 端口；端口被占用时需释放端口，或同时修改 Vite 配置与 Tauri 的 `devUrl`。

## 构建

只构建前端：

```powershell
npm run build
```

构建 Windows 桌面应用与 NSIS 安装包：

```powershell
npm run desktop:build
```

安装包输出在 `src-tauri/target/release/bundle/nsis/`，可执行文件位于 `src-tauri/target/release/`。安装界面提供简体中文和英文选项。

## 规则

1. 初始十列共 54 张牌，前四列各六张、后六列各五张，每列只翻开最底下一张。其余 50 张分五次发牌。
2. 可以把单张明牌放到点数大一的明牌下面，接牌允许不同花色。例如红桃 7 可以接到黑桃 8 下。A 是最小的牌，不能在 A 下继续接牌。
3. 整组移动要求牌组位于列尾，并且全部翻开、同花色、连续降序。例如黑桃 9、8、7 可以一起移动。
4. 空列允许放入任意单牌或合法牌组。发新牌前，十列都必须有牌。
5. 点击右下角牌堆，每列各发一张明牌。十张牌全部发完后再统一结算完整牌组。
6. 同花色 K、Q、J、10……2、A 连成完整一组时自动收走，集齐八组获胜。
7. 分数从 500 开始，每次有效移牌或发牌扣 1 分，每收齐一组加 100 分。无效操作不扣分。撤销会恢复上一步分数和步数，用时不会回退。

随机牌局不保证有解，可以使用撤销、提示或重开调整思路。

## 操作与快捷键

| 操作 | 快捷键 / 方式 |
| --- | --- |
| 移牌 | 点击来源，再点击目标列；或拖动合法牌组 |
| 撤销 | `Ctrl+Z`，macOS 浏览器也支持 `Command+Z` |
| 下一个提示 | `H`，连续点击轮换 |
| 发一行新牌 | `D` |
| 暂停 | `P`，点击“继续游戏”恢复 |
| 取消选中或拖拽 | `Esc` |
| 关闭规则 / 新游戏 / 重开弹窗 | `Esc` 或点击弹窗外部 |

首次有效操作后开始计时。打开弹窗、手动暂停或页面隐藏期间不会累计时间；在输入区域或弹窗内不会触发牌局快捷键。

## 本地存档

- 使用 localStorage，存档键为 `qinglv-spider:game:v1`，不连接服务器。
- 每次有效操作后保存，游戏进行中每约五秒保存一次计时检查点，页面隐藏或退出时补存。
- 浏览器与 Tauri 桌面版分别保存自己的牌局；不同浏览器、不同来源和不同设备之间不共享进度。
- 最近 200 步撤销记录随牌局保存。存储配额不足时，优先将持久化历史缩减为 20 步或 0 步来保住当前牌局，界面会说明；当前会话仍保留最近 200 步。
- 当前牌局损坏或版本不兼容时会准备一局新游戏；只有撤销历史损坏时保留当前牌局并清除历史。
- 存储不可用时仍能游玩，底部会提示无法保存。清除应用数据、浏览器站点数据或使用无痕窗口可能丢失存档。
- “新游戏”和“重新开始”均会替换当前存档，操作前会显示确认弹窗。

## 代码结构

```text
src/
  game/types.ts                  牌面、难度与牌局数据类型
  game/engine.ts                 洗牌、移牌、发牌、收组、提示和存档校验
  composables/useSpiderGame.ts   撤销、存档、计时和响应式会话
  components/PlayingCard.vue     纸牌正反面
  components/GameDialog.vue      弹窗与键盘焦点管理
  components/UiIcon.vue          本地 SVG 操作图标
  App.vue                       牌桌布局、拖拽与交互
  style.css                     绒面牌桌、纸牌及响应式样式
src-tauri/
  src/                          Tauri 2 原生入口
  capabilities/default.json     主窗口基础权限
  icons/                        已生成的 PNG / ICO 图标
  tauri.conf.json               窗口、内容安全策略与安装包配置
```

原生入口保持轻量，游戏规则全部运行在前端，不需要额外 Tauri 插件。扑克牌和操作图标由 CSS、Unicode 和本地 SVG 绘制，不加载外部素材或字体。

应用图标已包含在项目中。如需重新生成，可运行 `python scripts/generate_icons.py`，仅使用 Python 标准库；正常开发和打包不需要 Python。
